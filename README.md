# Qwen Git PWA

A Progressive Web App for Git operations + AI assistant.

## App Icons

The default app icon is `icon-*.png`. For a "Business Card" (BC) theme, use the BC-themed icons:

1. Generate `public/icon-bc-192.png` and `public/icon-bc-512.png` from the provided SVGs (`icon-bc-192.svg`, `icon-bc-512.svg`).
2. They feature a blue gradient "BC" on a dark background.

The manifest includes both sets of icons for fallback compatibility.
